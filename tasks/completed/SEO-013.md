# SEO-013 — Imágenes, rendimiento y accesibilidad

Completada: 2026-08-09T00:03:41.342Z

Criterios de aceptación:
- [x] Imágenes en WebP o AVIF vía astro:assets
- [x] srcset y dimensiones explícitas
- [x] Lazy loading fuera del viewport inicial
- [x] LCP y CLS revisados en las páginas más pesadas
- [x] Menú móvil accesible
- [x] Contraste de color conforme a WCAG AA para texto sobre la paleta de marca
- [x] Foco visible en elementos interactivos
- [x] Jerarquía de encabezados correcta en todas las páginas
- [x] Textos alternativos descriptivos en todas las imágenes de producto
- [x] Botones con área táctil y aria-label donde el texto visible no baste
